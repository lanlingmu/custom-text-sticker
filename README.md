# 自定义文字表情包

一个可以直接在浏览器里制作透明底微信表情包的小工具。

## 功能

- 修改文字、字体、字号、文字颜色和描边颜色
- 支持手动换行
- 调整字间距、行间距和描边粗细
- 更换配图，并自动裁掉 PNG 透明空边
- 配图可放左侧或右侧，文字对齐会联动
- 横向、纵向位置可从 0% 调到 100%
- 兼容带肤色修饰符的 Emoji，避免拆成两个字符
- 导出透明背景 PNG，可直接保存后上传微信表情

## 使用方法

直接打开 `index.html` 即可使用，不需要安装依赖。

在线版本：https://xianxian-sticker-studio.sh7wfkhmgp.chatgpt.site/

## 项目结构

- `index.html`：完整网页源码，包含样式与交互逻辑
